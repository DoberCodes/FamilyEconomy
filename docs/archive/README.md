# Docs Archive

This folder stores completed planning and historical tracking documents that are no longer actively edited.

## What Belongs Here

Move docs into this folder when they are primarily historical records rather than active planning references.

## Archived Files

- [mvp-backlog.md](mvp-backlog.md)
  - Purpose: Phase 1-4 MVP backlog checklist used to drive initial build-out.
  - Status: Completed historical planning record.

- [progress-log.md](progress-log.md)
  - Purpose: Session-by-session implementation log for the MVP and early expansion work.
  - Status: Historical execution timeline.

- [analytics-plan.md](analytics-plan.md)
  - Purpose: Phase 10 analytics instrumentation planning document.
  - Status: Completed planning artifact.

## Usage Guidance

- Keep active strategy and roadmap docs in the parent docs folder.
- Keep implementation-ready planning in active docs.
- Keep finished plans and logs in this archive folder.
