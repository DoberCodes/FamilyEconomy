# Product Brief (Phase 0)

## Product Definition

Family Economy is a kid-friendly household economy system that helps families build responsibility, saving habits, delayed gratification, and healthy money behaviors through everyday tasks and rewards.

## Core Principles

### Must Be

- Simple
- Playful
- Parent-controlled
- Educational through interaction
- Flexible
- Low-friction

### Must Not Feel Like

- Corporate software
- Accounting software
- A punitive system
- A technical finance product
- A rigid educational curriculum

## Audience

### Primary

Parents with children ages 7-10.

### Secondary

- Families with children ages 6-12
- Homeschool families
- Tech-forward households
- Financially minded parents

## Product Identity Guardrails

1. Default app mode is child-friendly.
2. Parent powers are protected and intentionally gated.
3. Economic lessons are implicit in interactions, not lectures.
4. Complexity stays hidden behind simple UI.
5. Family engagement is a first-class objective.

## Core Loop (MVP)

Earn -> Save -> Spend -> Goal

Everything in MVP must support this loop directly.
